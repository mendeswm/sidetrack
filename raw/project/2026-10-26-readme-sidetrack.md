# README.md — Sidetrack

> Source: https://github.com/qfertig/sidetrack
> Collected: 2026-10-26
> Published: Unknown

Lightweight GMS-free Spotify client built for D-pad/flip phones running Android, powered by librespot and Jetpack Compose. Features: Spotify Connect pairing, library browsing, playback controls, dark theme optimized for small screens. Max audio quality: 320 kbps Ogg Vorbis.
